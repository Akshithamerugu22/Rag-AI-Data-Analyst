# Final Year Project Report

## Title
Universal RAG-Based AI Data Analyst with Natural Language Query Planning

## Abstract
A hybrid AI analytics platform that accepts structured and unstructured data, profiles unfamiliar schemas, generates safe analytical SQL using an LLM, executes calculations using DuckDB, retrieves relevant context through RAG, and produces grounded explanations and visualizations. The architecture separates language understanding from numerical execution to reduce hallucinated analytical results.

## Objectives
1. Support multiple data formats.
2. Work with unfamiliar schemas.
3. Allow natural-language analytical questions.
4. Execute numerical calculations deterministically.
5. Ground explanations with RAG.
6. Produce visual and downloadable results.
7. Demonstrate scalable local analytics.

## Technologies
Python, Pandas, DuckDB, Streamlit, Sentence Transformers, ChromaDB, Gemini, Plotly, OpenPyXL, PyPDF and ReportLab.

## Modules
Data ingestion, schema inference, profiling, natural-language query planning, SQL validation, DuckDB execution, RAG retrieval, LLM explanation, visualization and report generation.

## Future scope
Forecasting, advanced statistical tests, anomaly detection, semantic data catalogs, persistent vector storage, authentication, cloud deployment and Power BI integration.
